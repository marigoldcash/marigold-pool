# marigold-pool

A mining pool for [Marigold](https://github.com/marigoldcash/marigold), and for Kaspa from the same code. ASICs and CPU wallets connect over stratum, every accepted share is counted, and when the pool's address receives a block reward it is split across the miners whose shares fall in the recent window, then paid out in batches. One program, one database file, one process beside the node.

It is being built step by step and is nearly ready for its first long run on the testnet. `marigold-pool serve` runs the whole pool from one settings file, `check` reads that file and says what it would do, `init` makes the pool wallet, `payout --now` pays what miners are owed, `rewards` shows the block rewards at an address, `miner reset` clears a miner's password, and `api` serves the pages from a database file. Miners are paid once a day, at a time set in UTC, whenever they are owed at least their payout level, which starts at 10 and which each miner can raise on the pool's page behind a password they choose. The settings and the service unit are in `deploy/`, and `scripts/deploy.sh` installs them without starting anything. To build and test, use `scripts/remote-build.sh`, which runs cargo on the build host and never on your own machine (`TEST=1`, `CHECK=1`, `LINT=1` and `FMT=1` select tests, a type check, formatting plus clippy, and formatting only). The pool is built against one pinned commit of the node, set in `Cargo.toml`, and one binary is built per chain: `chain-marigold` is the default, `chain-kaspa` is added in the last step.

The plan is [PLAN.md](PLAN.md): twelve steps, M0 to M11, each with the tests that prove it and the command that verifies it, ticked off as they pass. [CLAUDE.md](CLAUDE.md) tells a coding session how to work through it. Licensed under either of MIT or Apache-2.0, at your option.
